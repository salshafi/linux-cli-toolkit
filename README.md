# linux-cli-toolkit

Two small projects I did for my COMP301 (Linux) course at Centennial College. I'm putting them here because I used them to get comfortable with the Linux command line and I want to keep them somewhere I can look back at.

- **ms1-xampp-lamp** - set up XAMPP (Apache, PHP) on Ubuntu and ran a couple of PHP pages, including a form that posts to a PHP script. Includes screenshots.
- **ms2-text-tools-and-cron** - practice with grep, sed, find, awk and a simple cron job, with the commands and their output.

The PHP and HTML files in ms1 are the exercise files I wrote for the milestone. The sample data in ms2 (`access.log`, `students.txt`) is invented for the repo, not real logs or student records. Files that came with the course are not included.
