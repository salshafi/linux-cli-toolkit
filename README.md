# linux-cli-toolkit

Two small projects I did for my COMP301 (Linux) course at Centennial College. I'm putting them here because I used them to get comfortable with the Linux command line and I want to keep them somewhere I can look back at.

- **ms1-xampp-lamp** - set up a LAMP stack with XAMPP on Ubuntu and ran a couple of PHP pages, including a form that posts to a PHP script.
- **ms2-text-tools-and-cron** - practice with grep, sed, find, awk and a simple cron job.

The sample data in here (`access.log`, `students.txt`) is made up by me for the repo. The files that came with the course are not included.

Each folder has its own README with the commands I used and what they output.
